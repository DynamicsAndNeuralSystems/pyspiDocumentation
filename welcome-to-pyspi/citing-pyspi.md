# Citing pyspi

If you use _**pyspi**_ in a scientific publication, please read and cite this article:

{% hint style="success" %}
O.M. Cliff, A.G. Bryant, J.T. Lizier, N. Tsuchiya, B.D. Fulcher. [Unifying pairwise interactions in complex dynamics](https://doi.org/10.1038/s43588-023-00519-x), _Nature Computational Science_ (2023)_._
{% endhint %}

Note that [preprint](https://arxiv.org/abs/2201.11941) and [free-to-read](https://rdcu.be/dn3JB) versions of this article are also available. For a list of all publications using _pyspi_, visit this [page](../information-about-pyspi/publications-using-pyspi.md). If you have cited _pyspi_ in your published work, feel free to reach out and we'll add it to the ever-growing list of publications using _pyspi_.&#x20;

***
