# SPI Descriptions

{% hint style="info" %}
The documentation accompanying the toolkit, including the tables and descriptions of each SPI, represent the features and functionality of the original pyspi library as detailed in the [Supplementary Material ](https://www.readcube.com/articles/supplement?doi=10.1038%2Fs43588-023-00519-x\&index=0)of the original _pyspi_ paper. While we strive to keep our documentation as current and comprehensive as possible, our library of SPIs may undergo frequent updates and enhancements to align with the latest advancements and user feedback.&#x20;
